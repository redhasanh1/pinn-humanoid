The AI

Nothing it does is hand-coded. It practises.

Every skill starts as a blank neural network. The robot tries it thousands of times inside a physics simulation, keeps what works, and only then moves it onto real motors. Below is how that works, drawn so you can see it.

Everything the robot knows lives in the connections between these dots. Each line has a number on it, a weight. Learning means nudging millions of those numbers until the right inputs light up the right outputs.

  1. In: what the cameras see, where every joint is, and the instruction ("throw it in the hoop").
  2. Middle: layers that turn pixels into things like "ball, 1.8 m away, drifting left".
  3. Out: the next moves for the shoulder, elbow, wrist and every finger.

The pulses are one decision flowing through. The real brains we run have about 3 billion connections; this one shows the shape, not the size.

Physics-informed neural networks (PINNs)

A normal network only learns from examples. Give it six blurry measurements of a thrown ball and it will happily draw a curve that wiggles through all six, and is wrong everywhere in between.

A physics-informed network is also marked on whether its answer obeys the laws of motion. Its score has two parts:

loss = data error + λ · physics error

physics error = how far the predicted path is from acceleration = gravity + air drag, checked at hundreds of points where there is no measurement at all.

Turn the physics loss on and the curve snaps to a real arc. That is the idea the project is named after: the robot needs far fewer examples because physics fills in the gaps, and it can predict where a ball, a cup or its own arm will be before it gets there.

Heavy inference, fast reflexes

A big model is smart but slow; a motor needs a new target every 20 milliseconds. So the robot thinks in layers, like you do: you decide to catch a ball, and your spinal cord handles the last few centimetres.

BrainA 3-billion-parameter robot model (NVIDIA GR00T N1.7, π0.5) on a cloud GPU. Looks at the cameras, reads the instruction, plans the next 2 seconds. About once a second.
CheckerA large vision-language model that watches the plan and catches mistakes mid-move. We'll be using Cerebras's fast inference here. Several times a second.
ReflexSmall learned skills on the robot: intercept the ball, cushion the catch, release the throw. 50 times a second.
MotorsServos holding each joint where it was told. Every 20 ms.

Where this is going

Robots that learn overnight. Leave the simulation running, and the robot wakes up with a skill it didn't have yesterday: tried a hundred thousand times, in wind, from every angle, before it ever touches the real world.

Physics as a teacher. Physics-informed models let a cheap, 3D-printed robot predict how things will move, so it learns from a handful of real examples instead of millions.

Thinking at the speed of motion. Most robot brains get one thought a second. With inference fast enough to check its own plan many times a second, a robot can notice a slip mid-grasp and fix it before the cup falls.

All of it open. Printable parts, the simulations, the training code and the logs, on GitHub for anyone to build on.
